# 标注工具使用指南

## 快速开始

1. **打开工具**：双击 `tools/annotator.html` 在浏览器中打开
2. **加载图片**：拖拽图片到画布区域，或点击"选择文件"
3. **选择工具**：点击左侧工具栏切换圈定方式
4. **圈定区域**：用鼠标在图片上画出要提取的元素
5. **标记类型**：每次圈定完成后，在弹出的面板中选择该区域的类型
6. **导出 JSON**：全部圈定完成后，点击右上角"导出 JSON"

## 三种圈定方式

### □ 矩形选择
- **操作**：按住鼠标左键拖拽，松开完成
- **适用场景**：元素周围有留白，一个矩形框就能框住
- **快捷键**：按 `R` 切换

### ✏ 自由套索
- **操作**：点击开始绘制，移动鼠标画轨迹，再次点击或按 Enter 完成闭合
- **适用场景**：元素与其他元素交错排列，矩形框会把旁边的元素框进来
- **快捷键**：按 `L` 切换，按 `Enter` 闭合，按 `Escape` 取消
- **技巧**：画的时候不需要太精细，粗糙地圈一圈即可。工具会自动用 Douglas-Peucker 算法简化路径

### 🤖 AI 点击分割
- **前提**：需要先启动 SAM 服务（状态栏显示"已连接"）
- **操作**：单击目标元素，AI 自动识别边界
- **适用场景**：元素边界不规则但清晰可见
- **快捷键**：按 `A` 切换
- **注意**：如果状态栏显示"未连接"，需要先运行 `python scripts/sam_service.py`

## 区域类型说明

| 类型 | 图标 | 含义 | 后续处理 |
|------|------|------|----------|
| 文字区 | Aa | 文字区域 | OCR 识别 → 可编辑文本框 |
| 背景框 | ▢ | 纯色/渐变背景 | → PPT 形状（可调颜色） |
| 图标 | 🖼 | Logo/图标/小装饰 | 裁剪为 PNG |
| 整体保留 | 📷 | 复杂图片不分割 | 整块裁剪为图片 |
| 转 SVG | ✦ | 需要矢量化 | 转为 SVG（仅指定才转） |
| 装饰 | ~ | 纯装饰线条/图形 | 视情况处理 |

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `R` | 切换矩形工具 |
| `L` | 切换套索工具 |
| `A` | 切换 AI 分割工具（需要 SAM 服务） |
| `P` | 切换平移工具 |
| `Z` | 适应窗口大小 |
| `Delete` / `Backspace` | 删除当前选中的区域 |
| `Escape` | 关闭类型选择弹窗；取消套索绘制 |
| 滚轮 | 放大/缩小 |
| 拖拽空白区域 | 平移视图（平移工具下） |

## 导出说明

点击"导出 JSON"后，浏览器会下载两个文件：

1. **`annotation-manifest.json`** — 标注数据的清单文件
2. **`source_image.png`** — 源图片（与 manifest 配套使用）

将这两个文件放到工作目录后，运行后续的 AI 二次识别脚本即可。
